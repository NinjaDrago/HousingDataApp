# HousingDataApp
Overview

HousingDataApp is a tool designed to analyze and visualize housing-related data, providing insights into pricing trends, regional differences, and key statistical measures.

New Features / Updates

Inclusion of income data and mode: The application now incorporates household income datasets and calculates the statistical mode for relevant variables.

Expanded regional coverage: Added smaller towns and rural areas to improve the granularity of the analysis.

Database upgrade: Replaced CSV and XLSX data sources with SQL databases for improved reliability, scalability, and querying performance.
